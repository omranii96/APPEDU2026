# Script : l'importance d'un ITSM / ESM

Public : direction générale et DSI. 16:9, environ 45 s, voix off d'homme en français. Aucun chiffre inventé : le
film ne cite aucune statistique.

## Version A : « La porte unique » (recommandée)

Concept : l'arrivée d'un nouveau collaborateur, le cas que toute direction connaît. Chaque service a sa porte, sa
file, son tableau. L'ITSM met de l'ordre dans le service informatique, l'ESM fait de toute l'entreprise une seule porte.

| Temps | Voix | Mise en scène |
|---|---|---|
| Accroche | Un nouvel arrivant. Premier jour. Pas d'ordinateur, pas de badge, pas d'accès. | Un bureau vide ; trois cases à cocher qui restent vides, chacune barrée de rouge. |
| Gag muet (2,5 s) | *(silence)* | Il attend sur sa chaise ; l'horloge murale file ; la plante sur le bureau penche. |
| Diagnostic | L'informatique attend les RH. Les RH attendent la finance. Et chacun suit sa demande dans son propre tableau. | Trois portes de service, chacune avec sa file ; une demande ricoche de porte en porte ; trois tableurs différents. |
| Pivot (noir) | Et si tout passait par une seule porte ? | Noir ; une seule porte s'éclaire. |
| Solution | L'ITSM organise le service informatique : un catalogue clair, des tickets suivis, des délais tenus. L'ESM applique la même méthode à toute l'entreprise. Une seule demande déclenche tout : le poste, le badge, les accès, le contrat. Et la direction voit enfin où le temps se perd. | Le portail : catalogue, ticket qui avance d'étape en étape, délai respecté ; les services RH, finance, services généraux qui se branchent ; une demande qui coche les quatre cases ; un tableau de bord de direction. |
| Fin | [Marque]. Une seule porte pour tous vos services. | Carte de fin, un bouton, un curseur qui clique. |

À coller dans le générateur de voix :

```
Un nouvel arrivant. Premier jour. Pas d'ordinateur, pas de badge, pas d'accès.

L'informatique attend les RH. Les RH attendent la finance. Et chacun suit sa demande dans son propre tableau.

Et si tout passait par une seule porte ?

L'ITSM organise le service informatique : un catalogue clair, des tickets suivis, des délais tenus. L'ESM applique la même méthode à toute l'entreprise. Une seule demande déclenche tout : le poste, le badge, les accès, le contrat. Et la direction voit enfin où le temps se perd.

[Marque]. Une seule porte pour tous vos services.
```

## Version B : « Lundi, neuf heures »

Concept : la boîte mail de la DSI qui déborde. Plus centrée sur l'ITSM, l'ESM arrive en extension à la fin.

| Temps | Voix | Mise en scène |
|---|---|---|
| Accroche | Lundi, neuf heures. Votre DSI reçoit sa centième demande… par e-mail. | Une boîte de réception ; le badge rouge grimpe jusqu'à « 99+ ». |
| Gag muet (2,5 s) | *(silence)* | Un post-it « URGENT » se colle sur l'écran, puis un deuxième, puis un troisième. |
| Diagnostic | Une demande d'accès perdue dans un fil de discussion. Le même incident traité trois fois. Et aucun chiffre pour savoir ce que coûte tout ça. | Une bulle de messagerie qui disparaît dans le défilement ; trois techniciens sur la même alerte ; un tableau de bord vide. |
| Pivot (noir) | Et si chaque demande suivait un chemin ? | Noir ; un trait de lumière se dessine. |
| Solution | Avec un ITSM, chaque demande devient un ticket : priorisé, assigné, suivi jusqu'au bout. Les incidents se règlent plus vite. Les changements arrivent sans casse. Et vous pilotez enfin avec des chiffres. Puis l'ESM étend la méthode à toute l'entreprise : RH, finance, services généraux. Un seul portail pour tout demander. | Le ticket qui avance sur le chemin ; un incident résolu ; un tableau de bord qui se remplit ; les autres services qui rejoignent le même portail. |
| Fin | [Marque]. Vos services, enfin pilotés. | Carte de fin, un bouton, un curseur qui clique. |
