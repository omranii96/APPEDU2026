# Intercom

Source : https://faq.branvas.com/en/articles/15505423-fulfilling-tiktok-shop-or-etsy-orders-through-shopify (lu le 22/11/2026)

TikTok Shop and Etsy can be connected as sales channels in Shopify, but they don't share the customer's shipping address with Shopify (a privacy behavior, not an error). The order syncs with a blank address, so you must add it manually before fulfilling:

1. Find the original order in TikTok Shop Seller Center or Etsy shop manager and copy the buyer's full shipping address.

2. Open the matching order in Shopify → Edit shipping address.

3. Enter the address exactly as shown on the source platform (copy-paste to avoid typos; double-check name, street, city, postal code, country).

4. Fulfill as normal and add tracking within the platform's handling time to avoid late-shipment penalties.

Check for new marketplace orders regularly so addresses are entered before ship-by deadlines.
